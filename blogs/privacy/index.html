Privacy Policy

隱私權政策

適用於 OAuth 應用程式「Rclone Backup Access」· 最後更新 2026 年 9 月 7 日

「Rclone Backup Access」是一個個人自用的 Google OAuth 用戶端。 它的唯一用途，是讓擁有者透過開源工具 rclone 把自己電腦上的檔案，備份到自己的 Google 雲端硬碟。它不對外提供服務，也沒有其他使用者。

我們存取什麼

  • 權限範圍僅有 https://www.googleapis.com/auth/drive，且只作用於授權者本人的 Google 雲端硬碟。
  • 存取行為限於：讀取、上傳、更新擁有者自己的備份檔案與資料夾。
  • 不讀取通訊錄、郵件、日曆、相片或任何其他 Google 服務的資料。

我們不做什麼

  • 不收集、不儲存、不傳輸任何第三方使用者的個人資料。
  • 不將任何資料出售、出租或分享給第三方。
  • 不使用分析工具、廣告或跨站追蹤。
  • 不將取得的資料用於訓練人工智慧模型。
  • 沒有伺服器端資料庫：本應用程式完全在擁有者的本機電腦上執行。

憑證如何保存

OAuth 存取權杖與更新權杖僅保存在擁有者本機的 rclone 設定檔 （~/.config/rclone/rclone.conf），不會上傳到任何伺服器，也不會離開該台電腦。

如何撤銷授權

擁有者可隨時於 Google 帳戶權限頁面 移除本應用程式的存取權；撤銷後本機的權杖立即失效。

Google API 服務使用者資料政策

本應用程式使用 Google API 所取得的資訊，其使用與轉移均遵守 Google API 服務使用者資料政策， 包含其中的「限制使用」（Limited Use）規定。

English summary

“Rclone Backup Access” is a personal-use Google OAuth client. Its sole purpose is to let its owner back up their own local files to their own Google Drive using the open-source tool rclone. It requests only the https://www.googleapis.com/auth/drive scope and acts exclusively on the authorizing user’s own Drive. It has no other users, collects no third-party personal data, shares nothing with third parties, runs no analytics or advertising, and does not use any obtained data to train AI models. It runs entirely on the owner’s local machine; OAuth tokens are stored only in the local rclone configuration file and are never transmitted elsewhere. Access can be revoked at any time at myaccount.google.com/permissions. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: suenyulei@gmail.com.
